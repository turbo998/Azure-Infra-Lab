## 3) 12-dimension matrix for enterprise deep-research patterns
- D1 coverage: Map-Reduce offers strongest full-file coverage across 300+ documents. [EN013]
- D2 reasoning depth: Deep Research excels on open-ended multi-hop synthesis. [EN014]
- D3 interaction latency: Agentic RAG is best for 5–15 second responses. [EN015]
- D4 citation anchoring: human-in-the-loop workbench is strongest for paragraph-level verification. [EN016]
- D5 miss risk: Top-K retrieval can miss low-frequency control-right clauses. [EN017]
- D6 cost shape: many small-model extractions plus one merger model is often efficient. [EN018]
- D7 async reliability: Durable Functions handles 5–12 minute workflows safely. [EN019]
- D8 progress UX: Web PubSub enables real-time stage visibility and handoff. [EN020]
- D9 isolation: confidential VDR cases require strict offline private execution modes. [EN021]
- D10 auditability: claim-to-page citation gates are mandatory pre-export controls. [EN022]
- D11 best-fit workloads: M&A diligence, patent FTO, and contradiction reconciliation. [EN023]
- D12 anti-pattern: do not run diligence pipelines on low-coverage quick RAG alone. [EN024]

## 5) Five calculable Q&As
### Q1 Top-K miss mechanism on 350 VDR documents
- Top-K windows can truncate sparse but critical clauses across long files. [EN032]
- Map-Reduce full-scan extraction drives misses into explicit workflow controls. [EN033]
### Q2 Million-token single pass vs 25-way extraction plus one merge model
- Parallel extraction reduces mid-context forgetting risk in long single-pass prompts. [EN034]
- Synthetic estimates show better cost-recall balance for the parallel pattern. [EN035]
### Q3 Preventing 5–12 minute timeout failures
- Use Durable orchestration, Service Bus shards, and Web PubSub stage pushes. [EN036]
- Keep frontend polling on job state rather than long gateway-held requests. [EN037]
### Q4 Internal-only vs external-intel dual track
- Confidential deals enforce offline private-only tools. [EN038]
- Non-confidential tracks may allow external enrichment with source trust labels. [EN039]
### Q5 Citation gate before formal export
- Every claim must include source page and quoted evidence. [EN040]
- Unsupported-claim interception rate should remain in strict guardrail range. [EN041]

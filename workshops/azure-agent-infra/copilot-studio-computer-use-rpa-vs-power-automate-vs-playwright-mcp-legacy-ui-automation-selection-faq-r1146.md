## 3) 四类架构 12 维横向选型矩阵
- 维度1主战场：CUA=非标复杂，PAD=固定批量，Playwright=外门户，绞杀者=混合演进。 [ZH013]
- 维度2韧性：CUA抗页面漂移强，PAD对控件漂移敏感，Playwright受DOM稳定度影响，绞杀者将UI面收缩。 [ZH014]
- 维度3成本：CUA有视觉推理成本，PAD接近零视觉成本，Playwright容器成本可控，绞杀者综合最低。 [ZH015]
- 维度4时延：PAD最快，Playwright中位，CUA在复杂推理时更慢。 [ZH016]
- 维度5写安全：提交前都必须幂等键与人工复核。 [ZH017]
- 维度6审计：CUA截图强，PAD日志强，Playwright需主动截图/HAR。 [ZH018]
- 维度7并发：CUA受桌面池，PAD受bot池，Playwright受容器配额。 [ZH019]
- 维度8凭据：统一 Key Vault 与短期票据优先。 [ZH020]
- 维度9测试：PAD回归成熟，Playwright CI强，CUA需场景回放库。 [ZH021]
- 维度10技能：CUA偏业务协同，PAD偏RPA，Playwright偏工程。 [ZH022]
- 维度11最佳场景：各取所长，混合最稳。 [ZH023]
- 维度12反模式：不要用提示词做授权控制。 [ZH024]

FabCon & SQLCon 2026 巴塞罗那峰会：为 Microsoft Copilot 与智能体构建可信数据底座 FabCon & SQLCon 2026 in Barcelona: Building the Data Foundation for Microsoft Copilot and Agents

由微软 Azure Data 执行副总裁 Arun Ulag 发布。本次大会汇聚近 5,000 名数据专家，全面升级 Microsoft Fabric、Fabric IQ、Power BI 智能体应用构建、Rayfin (Fabric Apps)、OneLake 开放网络、自主数据工程智能体与 Azure SQL / Sovereign 混合主权数据方案。 Authored by Arun Ulag (EVP, Azure Data, Microsoft). Bringing together nearly 5,000 data professionals in Barcelona with sweeping innovations across Fabric IQ in Microsoft Copilot, Agentic App Creation in Power BI, Fabric Apps (Rayfin), OneLake IQ Sharing, Data Engineering Agents (Osmos), Fabric Observability, and Azure SQL Hyperscale & Azure Local.

Frontier Transformation Architecture
PILLAR 01 · FRONTIER TRANSFORMATION
Fabric IQ 深度赋能全新 Microsoft Copilot Fabric IQ Powering the New Microsoft Copilot
GA
  • 共享智能层 (Fabric IQ)：融合 OneLake 统一数据、Power BI 可信语义指标与 Ontology（本体）及实时情报，为人与 Agent 提供统一的业务理解。 Shared Intelligence Layer: Combines OneLake data, Power BI semantic metrics, ontologies, and real-time intelligence into a unified business context.
  • Copilot Chat & Cowork 正式版 (GA)：M365 Copilot 用户现可直接调用 Fabric 洞察，无额外 AI Token 成本；全新 Copilot Code 集成即将通过 Frontier 计划推出。 GA in Copilot Chat & Cowork: M365 Copilot customers tap into Fabric insights with no additional AI token costs; Code integration coming via Frontier program.
  • 零门槛复用既有资产：Power BI 语义模型与报表中的业务定义、核心 KPI 自动成为 Copilot 决策依据。 Instant Semantic Grounding: Existing Power BI semantic models and business definitions directly inform decisions in Microsoft Copilot.
PILLAR 02 · POWER BI & FABRIC APPS
Power BI 智能体应用构建 & Rayfin 全栈投产 Power BI Agentic App Creation & Fabric Apps (Rayfin)
Preview
  • 从看报表到造应用：在 Power BI Desktop 中基于语义模型用自然语言生成业务应用，支持数据录入、数据回写 (Write-back)、共享状态与业务流。 Beyond Dashboards: Generate operational apps in Power BI Desktop via natural language with inputs, data write-back, shared state, and workflows.
  • 普惠授权（含 Pro / PPU）：不仅限于 Fabric 容量客户，Power BI Pro 与 PPU 用户无需额外付费即可使用 Fabric Apps 及每个应用最高 1GB 的 Fabric SQL 数据库。 Included for Pro & PPU: Available at no additional cost to Power BI Pro, PPU, and Fabric capacity customers with up to 1 GB Fabric SQL Database per app.
  • 开源 Rayfin SDK & CLI 增强：自 2026 年 6 月发布以来已有数千名开发者采用；新增 TypeScript 后端函数、Secret Store、PostgreSQL 支持、默认私有访问及内置性能指标。 Open-Source Rayfin SDK & CLI: Adds TypeScript backend functions, Secret Store, PostgreSQL support, private-by-default access, and built-in metrics.
PILLAR 03 · ONELAKE OPEN DATA NETWORK
OneLake IQ Sharing 与多云生态扩展 OneLake IQ Sharing & Multi-Cloud Ecosystem
Preview + GA
  • IQ Sharing（预览）：跨团队、客户与合作伙伴安全共享受治理表/文件、Markdown 智能体指令与 RDF 本体（路线图将原生支持 Fabric IQ 本体与 Power BI 语义模型）。EY、S&P Global、TomTom、Financial Fabric、xMentium 已率先接入。 IQ Sharing (Preview): Share governed tables/files alongside Markdown agent instructions and RDF ontologies across org boundaries. Adopted by EY, S&P Global, TomTom, Financial Fabric, and xMentium.
  • 跨云零拷贝互联：Salesforce Data 360 双向集成（预览）、Google BigQuery 镜像（正式版 GA）、Dynamics 365 Business Central 深度集成。 Zero-Copy Cross-Cloud: Bidirectional Salesforce Data 360 integration (Preview), Google BigQuery Mirroring (GA), and deeper D365 Business Central integration.
  • 开放生态工具链：深化与 Atlan、dbt、ClickHouse 的原生协作。 Ecosystem Partners: Expanded integrations with Atlan, dbt, and ClickHouse.
PILLAR 04 · AUTONOMOUS DATA ENGINEERING & RTI
自主数据工程智能体 (Osmos) 与实时情报 Copilot Data Engineering Agent (Osmos) & Real-Time Intelligence
Preview
  • Data Engineering Agent（预览）：基于 2026 年初微软收购的 Osmos 技术打造，支持数据平台迁移、Lakehouse 现代化、性能优化与复杂 ETL 的受控自主规划与执行。 Data Engineering Agent (Preview): Built on Microsoft's acquisition of Osmos (Jan 2026) for autonomous platform migrations, lakehouse modernization, tuning, and complex ETL.
  • 跨 IDE 协同接力：继承工作区权限，无缝跨 GitHub Copilot、VS Code、Codex 与 Claude Code 启动、监控和引导同一工程任务。 Multi-Tool Orchestration: Seamlessly start, monitor, and steer tasks across Fabric, GitHub Copilot, VS Code, Codex, and Claude Code.
  • Real-Time Intelligence Copilot：自然语言生成实时看板、管理 Eventhouse 表/策略/Schema、提供成本与性能优化建议，并配合 Operations Agent 实现 AI 根因诊断。 Copilot in Real-Time Intelligence: Natural language Real-Time Dashboards, Eventhouse administration, schema optimization, and AI root-cause analysis.
PILLAR 05 · ONTOLOGY, AGENTS & OBSERVABILITY
本体构建、Apache Ossie 标准、全栈可观测与按需计费 Ontology Curation, Apache Ossie, Observability & Billing
Preview
  • Agentic Ontology 构建 & Apache Ossie：从语义模型、OneLake 数据和文档自动生成本体，支持自然语言业务规则与复用 Power BI 度量值；携手 Snowflake 等推进 Apache Ossie (Incubating) 开放语义元数据标准。 Agentic Ontology & Apache Ossie: Generate ontologies from semantic models/docs, define rules in natural language, reuse Power BI measures, and back Apache Ossie (incubating) with Snowflake.
  • Fabric 智能体升级：Data Agents 深度融合 Fabric IQ 本体；Build Agent with AI 模式支持读取数据字典与术语表；Operations Agents 新增预授权动作与根因分析（预览）。 Fabric Agents: Deeper Data Agent + Ontology integration, AI builder mode using glossaries/dictionaries, and Operations Agents with pre-approved actions & RCA.
  • 全栈可观测性 & 按需计费：跨工作区遥测汇聚至单一 Eventhouse、Monitor Hub 容量/Activator 告警；推出跨工作负载 On-Demand Billing（按需计费）与 Fabric Zero-Provisioned（零预置起步）。 Observability & On-Demand Billing: Multi-workspace Eventhouse telemetry, Monitor Hub capacity headroom, on-demand consumption billing, and Fabric zero-provisioned onboarding.
PILLAR 06 · DATABASE ESTATE & SOVEREIGN CLOUD
Database Hub、SQL Hyperscale 向量与主权云部署 Database Hub, SQL Hyperscale AI & Sovereign Estates
GA + Preview
  • Database Hub in Fabric（预览）& Database Agents：集中管控 SQL Server、Azure SQL、PostgreSQL、Cosmos DB 与 Fabric SQL；即将推出面向 Azure SQL 与 PostgreSQL 的 Database Agents（支持 Fabric 与 VS Code）。 Database Hub (Preview) & Agents: Central control plane for SQL Server, Azure SQL, PostgreSQL, Cosmos DB, and Fabric SQL; specialist Database Agents for SQL & PostgreSQL coming soon to Fabric & VS Code.
  • Azure SQL Database Hyperscale 突破：Serverless 自动暂停（预览）、弹性池密度提升至 50 数据库/池、192 vCore 计算规格（GA）；DiskANN 向量索引（GA）全面落地 Hyperscale、SQL MI 与 Fabric SQL。 Azure SQL Hyperscale Innovations: Serverless auto-pause (Preview), elastic pools up to 50 DBs/pool, 192 vCore compute (GA), and DiskANN vector indexes (GA) across Hyperscale, SQL MI, and Fabric SQL.
  • 主权与离线环境全面 GA：SQL Server on Azure Local (GA)、Azure Local Disconnected Operations / ALDO (GA)，以及 Microsoft Fabric 扩展支持 Microsoft 365 GCC High。 Sovereign & Edge GA: SQL Server on Azure Local (GA), Azure Local Disconnected Operations / ALDO (GA), and Microsoft Fabric expansion to M365 GCC High.

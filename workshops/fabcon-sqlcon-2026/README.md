## 📌 六大核心技术支柱概览 / 6 Strategic Innovation Pillars

1. **Fabric IQ 深度赋能全新 Microsoft Copilot (`GA`)**：统一 OneLake、Power BI 语义模型、Ontology 与实时情报，在 M365 Copilot Chat & Cowork 中正式可用（GA），无需额外 AI Token 成本。
2. **Power BI 智能体应用构建 & Rayfin 全栈投产 (`Preview` / `Available`)**：在 Power BI Desktop 中用自然语言生成支持 Write-back 的全栈业务应用（向 Pro/PPU/Fabric 容量用户免费附赠最高 1GB Fabric SQL）；开源 Rayfin SDK/CLI 新增 TypeScript 后端函数、Secret Store 与 PostgreSQL 支持。
3. **OneLake IQ Sharing 与多云开放生态 (`Preview` + `GA`)**：推出跨组织共享受治理数据、Markdown 智能体指令与 RDF 本体的 IQ Sharing（预览）；Salesforce Data 360 双向零拷贝集成（预览）与 Google BigQuery 镜像（GA）。
4. **自主数据工程智能体 (Osmos) 与实时情报 Copilot (`Preview`)**：基于 Osmos 收购技术推出 Data Engineering Agent，支持跨 Fabric、GitHub Copilot、VS Code、Codex 与 Claude Code 协同执行迁移与 ETL。
5. **本体构建、Apache Ossie 标准、全栈可观测与按需计费 (`Preview`)**：支持从语义模型与文档自动构建本体，联合 Snowflake 推进 Apache Ossie (Incubating) 开放语义标准；推出跨工作区 Eventhouse 遥测汇聚、On-Demand Billing（按需计费）与 Fabric Zero-Provisioned（零预置起步）。
6. **Database Hub、SQL Hyperscale 向量与主权云部署 (`GA` + `Preview`)**：Fabric Database Hub 与 SQL/PostgreSQL Database Agents；Azure SQL Hyperscale 192 vCore (GA)、Serverless 自动暂停（预览）、50-DB 弹性池；DiskANN 向量索引全面 GA；SQL Server on Azure Local、ALDO 与 Fabric M365 GCC High 正式 GA。

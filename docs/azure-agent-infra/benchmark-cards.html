7 / 7 · 我的结论

受治理运行时具备生产就绪度，容器内明文密钥模式仍不适用。

✅ Good fit
  • Coding Agent sandbox: ACA Dynamic Sessions for managed fast isolation; E2B when deep runtime control needed
  • Browser/CUA cluster: ACA Sandboxes or E2B with explicit pause/resume and WebSocket routing
  • Multi-tenant SaaS Agent Gateway: APIM AI Gateway + AKSClaw hard boundaries + Entra Agent ID
  • Financial zero-trust execution: Kata/Firecracker isolation + private networking + deterministic policy audit
⛔ Not for
  • Coding Agent sandbox: Gateway lanes that skip entropy bounds and tenant-scope revalidation
  • Browser/CUA cluster: Returning screenshot/video payloads as inline JSON blobs in LLM memory
  • Multi-tenant SaaS Agent Gateway: Gateway/MCP flows that bypass tenant I/O fairness contracts and isolation
  • Financial zero-trust execution: Regulated workloads without immutable eviction-lineage and policy replay verification

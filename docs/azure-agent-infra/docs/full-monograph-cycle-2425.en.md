# Cycle 2425 Monograph: Legal/M&A Deterministic OOXML Redline Agent Infrastructure

## A. Objective and scope
- Scope: procurement MSA/DPA review, M&A VDR diligence, and negotiation redlines.
- Objective: preserve clause integrity, citation exactness, and privilege isolation at high throughput.

## B. Core constraints
1. Forbid full-document regeneration; enforce span-level OOXML patching only.
2. Every citation must resolve to exact paragraph/span evidence.
3. Matter-level access, indexes, and keys must remain strictly isolated.

## C. Metric snapshot
- Untouched-clause preservation integrity: 100.0%
- Non-standard indemnity/LoL recall: 92.4%
- 5,000-doc VDR turnaround improvement: 63.8%
- Citation exactness: 98.6%

## D. Selection trade-offs
- Bulk swarm yields highest throughput for M&A diligence sweeps.
- Word add-in interaction provides deepest counsel control for negotiation loops.
- CLM webhook triage fits continuous intake and priority routing.

## E. Five-step rollout
1. Establish matter-level privilege domains and isolated search indexes.
2. Build clause trees and cross-reference dependency graphs.
3. Score risk with playbook policy and confidence controls.
4. Emit deterministic OOXML tracked-changes patches with AST integrity verification.
5. Escalate low-confidence/high-risk clauses to GC or outside counsel sign-off.

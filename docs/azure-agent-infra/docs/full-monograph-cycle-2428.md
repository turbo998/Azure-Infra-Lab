# Cycle 2428 专著：主权跨境驻留与签名交换 Agent 基础设施

## A. 目标与范围
- 范围：受监管行业跨组织、跨区域 Agent 协作。
- 目标：确保驻留边界不破、防止失控外传，并保证加密不可抵赖。

## B. 核心约束
1. 原始上下文必须驻留在本区域。
2. 跨境仅允许签名工件交换，不允许明文上下文直传。
3. 每次决策都要可审计回放（策略+身份+签名）。

## C. 指标快照
- 驻留策略违规拦截率：96.8%
- 跨境令牌拒绝率：93.7%
- 签名工件不可抵赖通过率：99.2%
- P0 数据外传事故下降率：84.4%

## D. 选型权衡
- 同域联邦依然是高敏场景默认路径。
- 签名工件交换是跨组织主生产路径。
- 明文跨境上下文共享不适用于受监管生产环境。

## E. 五步落地
1. 定义主权域与策略元数据契约。
2. 将 APIM 路由绑定驻留与意图策略。
3. 强制短时工作负载身份与吊销校验。
4. 出站工件使用 HSM 密钥签名，入站强制验签。
5. 定期执行拒绝事件与跨境交换审计回放演练。

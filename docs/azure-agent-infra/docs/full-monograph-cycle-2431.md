# Cycle 2431 专著：零售门店边缘视觉、需求感知与补货 Agent 基础设施

## A. 目标与范围
- 范围：5,000 门店全渠道需求感知与补货运营。
- 目标：降低 WAN 压力、加速缺货恢复、减少损耗、提升补货准确率。

## B. 核心约束
1. 门店边缘视觉推理必须在弱网场景连续运行。
2. 补货决策必须通过确定性 MILP 约束求解。
3. ERP 采购门禁必须对所有自动订单动作做强制校验。

## C. 指标快照
- 门店 WAN 流量下降率：87.6%
- 缺货检测到补货时延改善率：46.9%
- 生鲜损耗下降率：28.4%
- MILP 对比无约束下单准确率提升：41.7%

## D. 选型权衡
- 边缘优先架构最能保护带宽与门店自治连续性。
- 云端集中视觉运维简单但带宽压力高。
- 分层混合模式在韧性与复杂度之间更平衡。

## E. 五步落地
1. 启用 Arc 边缘推理与离线续跑机制。
2. 在 Fabric 流中融合 POS、电商、天气与活动信号。
3. 使用 MILP 安全库存与跨店约束进行补货求解。
4. 在 SAP/D365 门禁执行预算与异常阈值校验。
5. 持续跟踪缺货恢复、损耗与订单准确率指标。

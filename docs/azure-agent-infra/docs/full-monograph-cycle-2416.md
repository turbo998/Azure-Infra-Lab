# Cycle 2416 深度专论：生产轨迹蒸馏与后训练飞轮

## A. 目标与边界
- 场景：将生产推理轨迹持续转化为可训练资产。
- 目标：提升领域任务精度并降低长期推理成本。

## B. 核心约束
1. 未脱敏或未同意样本不得进入训练集。
2. 奖励函数必须由确定性验证器参与打分。
3. 发布前必须通过遗忘与安全回归门禁。

## C. 关键指标
- 蒸馏准确率提升：12.9%
- 月度 token 成本下降：29.0%
- 遗忘守门通过率：96.9%
- LoRA SFT TTFT P95：1.21s

## D. 方法权衡
- SFT 成本效率最佳，适合多数结构化任务。
- DPO 适合偏好对齐增强。
- RFT 在复杂策略问题上收益高但治理成本更高。

## E. 五步落地
1. 建立 OTel 轨迹采集与样本质量分层。
2. 部署 Purview/Presidio 脱敏与同意门禁。
3. 构建硬负例挖掘与奖励评分流水线。
4. 实施 SFT/DPO/RFT 影子评测与灰度发布。
5. 常态化监控遗忘回归与租户退出影响。

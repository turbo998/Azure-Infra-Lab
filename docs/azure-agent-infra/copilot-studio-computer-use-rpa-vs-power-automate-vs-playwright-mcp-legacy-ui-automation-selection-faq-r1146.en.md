## 3) 12-dimension matrix across four patterns
- D1 battlefield: CUA for non-standard work, PAD for fixed batch, Playwright for portals, Strangler for blended estates. [EN013]
- D2 resilience: CUA handles visual drift, PAD is selector-fragile, Playwright depends on DOM stability, Strangler shrinks UI blast radius. [EN014]
- D3 cost: CUA carries vision cost, PAD near-zero vision cost, Playwright elastic container cost, Strangler lowest blended cost. [EN015]
- D4 latency: PAD fastest, Playwright middle, CUA slower for complex reasoning. [EN016]
- D5 write safety: idempotency key and human review are mandatory before submit. [EN017]
- D6 audit: CUA screenshot-rich, PAD log-rich, Playwright needs explicit screenshots/HAR. [EN018]
- D7 concurrency: bounded by desktop pools, bot pools, or container quotas respectively. [EN019]
- D8 credentials: standardize Key Vault with short-lived secrets. [EN020]
- D9 testing: PAD regression packs, Playwright CI strength, CUA replay corpus need. [EN021]
- D10 skills: CUA business-heavy, PAD RPA-heavy, Playwright engineering-heavy. [EN022]
- D11 best fit: each pattern has a lane, hybrid is often strongest. [EN023]
- D12 anti-pattern: never rely on prompts for authorization control. [EN024]

## 7) Scenario A: life insurer with 20-year Win32 core
- Architecture: read-replica lookup + PAD for standard edits + CUA for non-standard exceptions. [EN049]
- Dual approval for high-value changes and beneficiary updates. [EN050]
- Pre-submit readback verification and idempotency checks. [EN051]
- Synthetic gain: complex cases reduced from 36 minutes to 14 minutes. [EN052]
- Evidence chain: screenshots, submission_id, and approver identity. [EN053]
## 8) Scenario B: global freight group across 45 portals
- Architecture: ACA ephemeral Playwright MCP pools with DOM-first and vision fallback. [EN054]
- Credential model: Key Vault managed secrets with short-lived injection. [EN055]
- Injection defense: sanitize portal text before prompt context usage. [EN056]
- Blob WORM stores booking receipts and proof screenshots. [EN057]
- Synthetic gain: status delay reduced from 4 hours to 18 minutes. [EN058]

## 5) 五组可复算 Q&A
### Q1 单母本RAG vs 24国语分库成本
- 设5万页手册，预翻译24语每页$0.09，首轮成本约$108,000。 [ZH032]
- 单母本RAG仅维护中英母本与检索层，年化维护成本可降 40%+。 [ZH033]
- 版本过期差错率：分库模式因发布不同步可上升到 3.2%。 [ZH034]
### Q2 非拉丁语系Token膨胀临界点
- 阿语/泰语/日语混输场景，Token 膨胀系数可达 1.25~1.9。 [ZH035]
- 当膨胀系数>1.5 且会话量高时，前置翻译可更经济。 [ZH036]
### Q3 零容忍术语锁定实现
- 流程：术语抽取 -> 词典校验 -> 翻译后比对 -> 失败拦截。 [ZH037]
- 指标：术语拦截率=拦截数/总命中，目标 p95>=0.98。 [ZH038]
### Q4 混输检索权重
- 当地语言描述 + 英文故障码：向量召回 0.62，BM25 精确 0.38 可作起始。 [ZH039]
- 再按语种命中率反馈动态调权。 [ZH040]
### Q5 Front Door + APIM 主权路由预算
- 以三区域 active-active 估算，基础网关与路由成本约上浮 18%~26%。 [ZH041]
- 但可显著降低跨境合规风险与数据驻留罚损。 [ZH042]

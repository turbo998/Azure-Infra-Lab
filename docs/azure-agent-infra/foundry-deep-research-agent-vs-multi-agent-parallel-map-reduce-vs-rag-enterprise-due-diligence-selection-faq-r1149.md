## 3) 四类企业深度研究架构 12 维矩阵
- 维度1覆盖率：Map-Reduce 对 300+ 文件全量覆盖最强。 [ZH013]
- 维度2推理深度：Deep Research 对开放问题多跳推演更强。 [ZH014]
- 维度3交互时延：Agentic RAG 在 5–15 秒问答最优。 [ZH015]
- 维度4证据锚定：人机协同工作台对逐段引用核验最强。 [ZH016]
- 维度5漏检风险：Top-K RAG 可能遗漏控制权条款。 [ZH017]
- 维度6成本形态：并行小模型抽取+单路大模型归并常更经济。 [ZH018]
- 维度7异步可靠性：Durable Functions 对 5–12 分钟任务更稳。 [ZH019]
- 维度8进度可视化：Web PubSub 可实现阶段推送与人工介入。 [ZH020]
- 维度9隔离需求：涉密VDR必须支持纯内网运行模式。 [ZH021]
- 维度10审计要求：论断-页码逐句核验门是出报告前提。 [ZH022]
- 维度11最佳场景：并购尽调、专利FTO、跨文档矛盾核验。 [ZH023]
- 维度12反模式：禁止把低覆盖快问答当作尽调主引擎。 [ZH024]

## 5) 五组可复算 Q&A
### Q1 350份VDR文档下 Top-K 漏检机理
- Top-K RAG 受召回窗口限制，跨文档低频条款易被截断。 [ZH032]
- Map-Reduce 全量逐份抽取可把漏检风险压到流程层可控。 [ZH033]
### Q2 百万上下文 vs 25路并行抽取+1路归并
- 并行小模型抽取可降低单路长上下文遗忘风险。 [ZH034]
- synthetic估算：并行方案在成本与召回平衡上更优。 [ZH035]
### Q3 5–12分钟异步任务防超时
- Durable Functions 编排 + Service Bus 分片 + Web PubSub 阶段推送。 [ZH036]
- 前端只追踪任务状态，不阻塞网关请求生命周期。 [ZH037]
### Q4 内网隔离与外网情报双轨策略
- 涉密项目强制禁外网，仅允许VDR内网工具链。 [ZH038]
- 非涉密可开放行业情报补证，但需分级标注来源可信度。 [ZH039]
### Q5 导出前引用校验门
- 每条结论必须绑定原文页码和段落锚点。 [ZH040]
- 无据论断拦截率应持续维持在高阈值区间。 [ZH041]
